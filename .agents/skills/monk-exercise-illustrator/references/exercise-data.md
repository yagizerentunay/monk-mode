# Exercise and media data

- `data/free-exercise-db/exercises.json` is Monk Mode's pinned source. `npm run data:exercises` generates `public/data/exercises.json` (slim list) and `public/data/instructions.json` (ID → steps). Never hand edit the generated pair.
- `src/lib/exercises.ts` loads the slim list, lazily merges `src/lib/curatedExercises.ts`, and uses a pinned jsDelivr `imageUrl` for legacy `images`. `src/lib/useExercises.ts` adds custom exercises and user muscle fixes. An exercise's `illustration` is a local `BASE_URL` path and takes precedence in `ExerciseBrowser.tsx`; `Workout.tsx` still uses `images[0]` directly. `MuscleMap.tsx`/`muscles.ts` show workout volume by broad muscle group; they are not an anatomical illustration mask.
- `public/exercises/` holds local WebP illustrations. Existing art informs palette and visual language, not source rights. Legacy `images` are upstream JPG paths, not local or Atlas paths.
- Atlas records live in `data/exercises/`; `schemas/exercise.schema.json` is authoritative for `media`. Every media object currently requires `path`, `role`, `alt`, `creator`, `sourceUrl`, `license`, and `redistributionEvidenceUrl`. `role` is `start`, `finish`, or `animation`; `alt.en` is required and `alt.tr` is supported. `data/id-registry.json` manages permanent Atlas IDs. `src/monkAdapter.ts` currently maps media paths into Monk `images` without URL resolution, so direct deployment through that adapter would be wrong.
- Atlas `media/exercises/barbell-bench-press.png` is existing `finish` media. Do not delete, replace or silently demote it. Atlas `barbell-bench-press` currently lists chest and triceps as primary; Monk `Barbell_Bench_Press_-_Medium_Grip` lists chest primary and shoulders/triceps secondary. Its explicit medium grip is also more specific than the current Atlas name/record. Therefore this pilot cannot automatically claim equivalence or add `legacyIds`.

For a confirmed match, compare equipment, grip, range of motion, movement pattern and muscle roles; record any differences in the manifest. A near-name collision or unresolved variation remains `needs-human-review`, with no Atlas JSON change. Preserve the original source URL and rights provenance for each original asset. `dist/` is generated.
