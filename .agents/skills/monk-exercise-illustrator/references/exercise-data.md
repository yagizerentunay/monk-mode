# Exercise and media data

- Open Exercise Atlas is the single source of Monk Mode's catalog. `npm run data:atlas` (see `docs/atlas-data.md`) fetches the Atlas commit pinned in `data/atlas.lock.json` and generates `public/data/exercises.json` (library, Turkish instructions included), `public/data/legacy-exercises.json` (names of old free-exercise-db ids) and `public/exercises/*`. Never hand edit these; to add or fix an exercise or picture, change the Atlas record and re-pin with `npm run data:atlas:update`.
- `src/lib/exercises.ts` loads the library and the legacy table; `src/lib/useExercises.ts` adds custom exercises and user muscle fixes. A record's `illustration` is a local `BASE_URL` path shown by `ExerciseBrowser.tsx`, `Workout.tsx`, `SwapSheet.tsx` and `Library.tsx`. `MuscleMap.tsx`/`muscles.ts` show workout volume by broad muscle group; they are not an anatomical illustration mask.
- `public/exercises/` holds the WebP illustrations copied byte for byte from Atlas `media/exercises/`. Existing art informs palette and visual language, not source rights.
- Atlas records live in `data/exercises/`; `schemas/exercise.schema.json` is authoritative for `media`. Every media object currently requires `path`, `role`, `alt`, `creator`, `sourceUrl`, `license`, and `redistributionEvidenceUrl`. `role` is `start`, `finish`, `reference` (one picture) or `animation`; `alt.en` is required and `alt.tr` is supported. `data/id-registry.json` manages permanent Atlas IDs. Monk Mode's own consumer is `src/lib/atlasAdapter.ts`: runtime id is `legacyIds[0]` (else `atlas:<id>`), the picture is `reference`, then `finish`, then `start`. Never change a `legacyIds` entry of a record that already has one: it is a user-data id.
- Atlas `media/exercises/barbell-bench-press.png` is existing `finish` media next to the Monk Mode `reference` picture. Do not delete, replace or silently demote either.

For a confirmed match, compare equipment, grip, range of motion, movement pattern and muscle roles; record any differences in the manifest. A near-name collision or unresolved variation remains `needs-human-review`, with no Atlas JSON change. Preserve the original source URL and rights provenance for each original asset. `dist/` is generated.
